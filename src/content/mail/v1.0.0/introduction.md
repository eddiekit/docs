# Introduction to @eddiekit/mail

`@eddiekit/mail` is a powerful email utility for SvelteKit, supporting Svelte components as templates.

## Features

- **Svelte Templates**: Use `.svelte` files to design your emails
- **Multi-provider**: SES, SMTP, and more
- **Type Safe**: Fully typed mailables

## Installation

```bash
pnpm add @eddiekit/mail
```
