# Introduction to @eddiekit/captcha

`@eddiekit/captcha` provides a simple integration for Cloudflare Turnstile in SvelteKit applications.

## Features

- **Svelte 5 Component**: Easy to use Turnstile widget with Svelte 5 runes support.
- **Server-side Verification**: Simple utility to verify tokens with Cloudflare's API.
- **Light/Dark Mode**: Support for light, dark, and auto themes.

## Installation

```bash
pnpm add @eddiekit/captcha
```
