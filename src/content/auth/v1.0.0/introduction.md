# Introduction to @eddiekit/auth

`@eddiekit/auth` provides high-level authentication utilities built on top of `@eddiekit/session`.

## Features

- **Multi-provider**: Support for Password, OAuth, and more
- **Secure**: Uses Argon2 for password hashing
- **Easy to use**: Simple API for login, registration, and logout

## Installation

```bash
pnpm add @eddiekit/auth
```
