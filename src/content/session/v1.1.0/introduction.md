# Introduction to @eddiekit/session v1.1.0

This version introduces many performance improvements and a new `Redis` store.

## What's New

- **Redis Store**: High performance session storage using Redis.
- **Improved Caching**: Built-in caching for session lookups.
- **New Middleware**: Simplified SvelteKit middleware.

## Installation

```bash
pnpm add @eddiekit/session@1.1.0
```
