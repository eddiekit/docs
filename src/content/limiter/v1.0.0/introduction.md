# Introduction to @eddiekit/limiter

`@eddiekit/limiter` provides a flexible rate limiting solution for SvelteKit applications, supporting multiple storage backends.

## Features

- **Extensible Stores**: Use the built-in `MemoryStore` or implement your own (e.g., Redis, Database).
- **Simple API**: Easy-to-use `check` method for rate limiting.
- **SvelteKit Ready**: Designed to work seamlessly in form actions, hooks, and API routes.

## Installation

```bash
pnpm add @eddiekit/limiter
```
